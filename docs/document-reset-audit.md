## 问题定位

1. spec原来确有视频要求，但§8.2默认角色流、完整场景按需，缺少用户所说的在场感硬门槛。
2. 计划把高风险媒体验证留在受阻B2，连续零费用批次转向契约/保存/控件。外围进度成为可见成果，核心体验始终缺失。
3. 504测试验证固定样本与程序事件，没有观察“实际看听一段情境→参与”的证据。把独立工程审查通过紧接产品验收邀请，容易误导。
4. 网络场景链接路线、来源声音例外、真人素材到AI角色的明确过渡没有完整规格。
5. PROJECT、rules、plan、README存在“仅B1批准／0项开发／全部费用0”等过时状态；已在当前层明确纠正，旧段落作为历史保留。
