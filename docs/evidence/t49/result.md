## 已验证的内部流程

1. 服务端只从签封 Cookie 识别归属；客户端 owner、邮箱和时间不能授予权限。
2. 两个合成账号各自保存和恢复不同的课程、句子位置及听／练模式。
3. 课程通过 T47 契约后存入现有内存替身；既有课程不能被更新请求悄悄替换。
4. 错版本、错句子、非法模式、角色变化和目标版本变化会被拒绝，其他字段不部分写入。
5. 过期、缺失、篡改会话不能读取或修改；撤销／删除后旧更新不能恢复记录。
6. 读取与列表返回深拷贝，调用方改动返回内容不会改写存储；新建存储实例不保留旧记录。
7. T48 真实状态经过保存、恢复后保持材料、指纹、角色、位置和模式；恢复建立新播放会话并拒绝旧播放回执。
8. 实际导出的 HTTP 路由支持往返，响应禁止缓存，过期判断使用服务端当前时间。
