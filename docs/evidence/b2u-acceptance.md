## 本地操作（无需登录）

地址：http://127.0.0.1:3000/ 。启动命令：项目目录执行 `npm run start -- --port 3000`，保持该进程运行；构建文件不存在时先 `npm run build`。

1. 选择熟悉的辅助语言，点击“合成课程演示”。应能切换场边家长交流、点餐两份不同样本，看见角色、对白和少量母语帮助。
2. 点击“打开听练操作”→“开始示范（无声音）”→“模拟本句结束”。当前句子和角色随操作变化。这里没有真实声音，无需等待播放。
3. 试整段、章节、单句、所选区间重复；结束句早于起始句时拒绝应用。
4. 切换对练演示，应由对方开场；可以返回“只看示范”。切换课程后旧循环和播放状态清除。
5. 未登录应看到“登录 Google 后才能保存”，不显示可用的保存操作。这是本地可验收边界。

## 保存恢复：自动化证据与人工前提

本批自动测试用合成签名身份连接真实内部处理器及内存存储，覆盖保存后刷新恢复、句子和模式、两课程分别恢复、删除撤销、换号、过期、迟到响应、存储失败和4KB拒绝。不是本轮真实Google端到端验收。

人工验证需有已配置Google登录且部署本批版本的授权环境。本地预览没有因此自动获得OAuth配置，旧线上版本也没有更新；无需为本批将密钥粘贴到聊天或假定线上已有新功能。

具备该环境后：登录→保存当前课程与位置→刷新→重新打开课程演示→恢复这条课程；应恢复句子和模式但不自动播放。可再试删除或撤销，并刷新确认记录消失。异语记录需切回原辅助语言恢复。
