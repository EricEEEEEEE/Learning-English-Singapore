## 已实现的可见行为

- Google 签封会话的真实 HTTP GET/POST/PATCH/DELETE 入口只从请求 Cookie 判定归属；生产导出使用 `Date.now()`。请求体中的 owner、email、now 不参与授权，响应不返回内部 owner。
- 场景确认后，登录用户可保存版本号和手动填写的播放位置，刷新后可查看、更新、撤销或删除；未关联当前本机场景的旧临时记录单列，不能仅因版本号相同而复用。
- 本机引导、场景、练习及学习偏好按账号分区；账号切换时，旧账号画面在新数据加载前隐藏。收到 401、跨标签账号标记变化、窗口重新聚焦或定时检查时重验会话。
- 页面持续声明流程演示、本地临时记录、无真实音轨或视频、服务重启可能丢失；服务端只保存版本号和位置，不上传用户目标正文。
