## 当时的产品路径

用户用母语描述自己的生活任务 → 简短确认角色、目的与学习起点 → 生成并保存5–8分钟连贯场景课程 → 看英文字幕完整示范 → 学带母语释义的词汇短语 → 学带母语翻译的完整句子 → 看回答字幕轮流接话 → 无答案提示的第一视角语音对练。

每一步均可重复、返回；课程存入本人账户，同版视频、台词、翻译和练习对应。听第一、说第二，不考读写。对象涵盖新加坡支持地区的所有成人新来者，尤其包括近零基础、怕开口者。五种现有辅助语言保留；尊重包括新加坡英语在内的口音和方言。

场景不限酒店，也包括孩子party、集体家长会、一对一家长会等。输入必须影响人物、任务和交流内容，不能只换标题。第一次示范只有英文字幕；母语释义在后续教学页出现。对方先开场，之后等待用户真实开口；沉默不自动推进剧情、不冒称用户已说。固定声音触发播放不等于理解自由回答。

5. T64候选：长片连贯性、不同真实需求及手机端完整五步验收。不可用12秒自动升级为5–8分钟完成。
