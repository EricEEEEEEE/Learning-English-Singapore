# 聚会场景多段短课：执行候选

## 已确认与本次目标

用户已认可16.25秒聚会成片的视觉表现和对话节奏；不重开该验收。本候选只补约60秒、多段连续课程的证据，不包含第五步自由语音、真实账号迁移或云部署。

本方案尚未扩大付费请求授权。本轮仅准备，不生成、不充值。总计USD26继续有效，最多1美元仍仅作延迟结算容差，不作为新增计划支出。

## 内容与执行顺序

1. 同一生日聚会、同一成人家长与学习者画外音，完成打招呼、孩子同班、请求重复、聊活动、礼貌结束五个回合。沿用最多10句/5回合的现有契约；不为了凑时长加入复杂长句或空白音轨。
2. 先审脚本与五语帮助文案。现有结构校验只保证字段齐全，不保证翻译准确；尤其核对“我的孩子的班级”等亲属与指代关系。词汇及句子必须来自本版对白。
3. 如获新增调用批准：最多1次文本请求、10次逐句语音。测量音轨，目标约60秒且总长不得超过现有60秒限制；不足则如实报告，不自动再生成或拉慢凑数。
4. 按现有分段器在句间分段，每段不超过20秒、最多4段。先保存并试听全部音轨，再确定视频逐段费用与提交清单。
5. 角色连续性是先决检查：需核实当前供应商音轨驱动接口是否允许共同参考图或前段衔接。仅重复文字提示不能保证同一人物。未确认可执行方案前不批量提交视频；必要时单独提出可选路线供用户决定。
6. 每段最多提交1次，未知提交不重试；复用成功段。逐段检查说话角色、画外音时人物是否停止说话、字幕对应和段落切换。短尾差只在现有严格范围内修复。
7. 成片和同版学习材料私有保存，前四页各重复播放两次，确认重播没有模型请求；核对跨账号拒绝与恢复读取。保留原16.25秒课程。

## 费用和停止条件

- 最多新增：1次脚本、10次语音、4次视频；这是申请范围上界，不代表已经批准或一定用满。
- 历史支出、既有2.65美元预留及新请求共用原账本。未取得最终费用前不释放未知预留，也不将预留描述成实际支出。
- 执行前核对当日价格、实际余额及每步预留；本方案不重复使用旧价格当作当前报价。
- 超过计划余额、音轨总长超过60秒、任一段超过20秒、角色连续性方案不成立、供应商结果不确定：暂停相应付费步骤，保存已有素材与原因，不自动修订预算。

## 验收与退回

技术：记录每段来源、请求ID、时长、哈希及实际生成等待时间；全片解码及课程契约通过，网页前四页可操作，重播模型请求为零。

体验：用户观察多段人物是否一致、角色轮换自然、语速可跟随、场景有连贯含义。自动测试不替代体验反馈。

失败退回：保留已验收16.25秒版本及全部实验记录，不上线、不覆盖、不自动追加费用。

人类团队：约1–2天；AI协作：约2–4小时主动工作，供应商等待及用户试听时间另计。供应商连续性能力仍需核查，此估计不是交付承诺。

## 官方接口核查（2026-09-30）

- [异步音频驱动视频](https://docs.ltx.io/api-documentation/api-reference/async-video-generation/submit-audio-to-video)允许同时提交 `audio_uri` 与可选 `image_uri`（首帧），也支持配合首帧的 `last_frame_uri`。fast模型720p输入音轨最长20秒。可利用已有样片帧作后续片段首帧，这是候选连续性路线，文档不保证人物跨段完全一致或角色口型正确。
- [输入格式](https://docs.ltx.io/input-formats)允许JPEG/PNG/WebP，图像Data URI编码体积上限7MB。可从已有虚构成人样片本地提取图片，无需另付图片生成费或公开托管图片；付费视频提交仍属新增请求。
- [价格](https://docs.ltx.io/pricing)核查：ltx-2-5-fast的720×1280音频驱动视频为输入音轨每秒USD0.09；60秒基础视频费USD5.40，未包含文本、语音、税或结算差异，非本批含税硬上限。
- 代码 `lib/generated-video.ts` 当前仅发送音轨、提示词、模型、分辨率及帧率，尚未接入参考图。因此不能把文档支持说成产品已有。

建议后续实现：先离线增加可选首帧输入的格式/大小/完整性测试，并绑定到对应持久视频提交意图；保留旧任务兼容。实际多段生成前选定参考帧、核查音轨及预算，执行第一段后观察人物连续性，再决定是否提交剩余段，失败不自动重试。仅使用上一段尾帧可能累计人物漂移；同一固定首帧可能产生动作跳变，两者均需试片而非承诺。
