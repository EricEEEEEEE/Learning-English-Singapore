# B2U：零费用课程操作界面

2026-09-23，用户确认“按照你说的这个方向，下一步的建议继续”，授权把 B2P 已验证能力接到可操作演示界面。沿用零付费请求、不发布和 USD25 绝对上限；不读取或修改真实密钥，不调用模型、语音或视频服务。

## 交付与顺序

1. T50：在已有五种辅助语言入口后提供明确的“合成课程演示”入口。提供至少两份用途不同的固定合成样本；用户能查看目的、双角色和逐句英文，必要的母语帮助与英文分开。通过 T47 契约进入 T48 状态；不把用户任意描述套进模板后称为理解或生成。未登录可预览。
2. T51：在同一界面选择整段、章节、单句、A-B，手动模拟一句结束并看到当前角色与句子变化；切换对练时由对方先开场，允许只看示范。明显标注没有真实声音、视频、麦克风或自由对话。使用 T48 状态机，切换样本后不沿用旧状态或旧播放回执。
3. T52：已登录用户能显式保存、列出并恢复自己的合成课程、句子位置和模式，能撤销或删除；未登录提示登录后才能保存。通过现有签封会话及 T49 接口，不由浏览器指定 owner。刷新后从服务端恢复；换号、会话失效、迟到响应不得显示旧账号课程。服务重启记录消失、网络失败、超限均明确提示，不能假报成功。

## 验收

- 三项分别执行红考题、红档、实现、全量验证和独立审查；不修改已冻结旧考题。
- 浏览器覆盖 320px、390px、1280px；五种辅助语言都能进入，控件键盘可达，母语文案继续标识待人工审查。
- T50 检查两个不同样本、角色与句子、演示说明、返回入口。
- T51 检查四种重复范围、合法／非法 A-B、同版本听练衔接和切换样本；“模拟一句结束”不能伪装音频播放。
- T52 检查保存、刷新恢复、撤销／删除、双账号切换、失效、失败及迟到响应。HTTP 身份边界沿用 T49，并保留实际导出路由回归。
- 最后给用户一条可操作路径；验证本批实际操作，不要求重验旧流程。

## 限制、风险、回退

这是交互流程演示，不是英语学习产品正式交付。无 AI 生成、真实听说或教学效果证据；现有 B02、M0、T13 等依赖不变。

保留 4096 字节请求上限，样本必须在上限内；保存前和失败时明确提示。仅进程内存记录，恢复不保留循环区间和中途对话上下文，恢复不自动播放。已有课程内容固定，变化使用新记录，不静默覆盖已保存材料。

保留旧演示路径；新入口与组件独立接入现有模块，不重构整站、不改生产 OAuth 或数据库。回退时停用新入口即可回到旧演示，无生产数据迁移。实施不增加依赖。

人类团队预计 15–24 小时；AI 协作预计 6–10 小时，均为投入时间估算，人工语言审查另计。
