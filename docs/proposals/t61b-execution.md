## 顺序与验证

1. 脚本适配：按用户需求调用结构化脚本接口，拒绝缺角色、无来源词组、缺五语翻译、超句数与超输入限制；模型拒绝/无效输出保留失败，不进入音视频。先用HTTP替身验证真实请求与解析路径，不只测试空壳接口。
2. 分角色语音：固定模型、声音与请求数；保存原始台词和实测时长，不预填字幕时间；超20秒分段或总60秒即停在视频请求之前。音频输出实际费用和听审未确认前不自动进视频。
3. LTX异步适配：提交前持久保存意图，提交后保存job ID；超时未知不重发，已有ID只查询。每段成功资产复用。模拟成功不能写成真实ready。
4. 本地组装：媒体完整、时长/格式合格后拼接，生成同版字幕/词句/回合，调用T60校验器；失败保持不可学习。支持本地验证入口，不把课程复制到公开部署。
