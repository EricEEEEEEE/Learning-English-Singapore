# X2 本地声音独立审查说明（招募前草稿）

**状态：未招募、未联系、未评分。** 本说明供项目负责人审核审查方式，不构成已取得本地或教学认可。项目把新加坡英语视为正当、自然的本地英语变体；不要求学习者或声音模仿单一族群口音，也不把本地表达当作错误。

## 人员与素材门槛

- 两名能评判新加坡日常英语的独立审查者，应具有不同的使用背景；由各人说明自己的相关经验，不按族裔、国籍或一种口音代替能力判断。两人不能讨论分数或看对方结果。任一维度意见相差超过1分或对放行有分歧时，再由第三名独立本地审查者处理。
- 另由教学审查者核对近零基础短句、词汇支撑和场合语域；声音好听不能代替可教性。简体中文、印尼语、日语、韩语及Hindi的标注分别待相应母语审查，不用开发者自评替代。
- 负责人先确认匿名审查ID、资历、独立性、可用时间、报酬安排、联系授权及素材使用/撤回方式。未落实这些项目，不发送招募信息或音轨。
- 音轨只用虚构成人角色和非识别性场景。若以后使用真实声音样本，必须另核本人授权、账号资格及数据链；内置声音的AI生成属性应向实际学习者清楚披露。

## 盲评流程

1. 冻结[x2-script-drafts.tsv](x2-script-drafts.tsv)与[矩阵](matrix.csv)的版本，并由教学负责人先审脚本；未审本地词保持候选标签。每个pair用同一句英文生成TTS示范与Realtime角色输出。记录模型、voice、速度/提示、真实音轨hash和版本，不根据结果改原始脚本或覆盖失败样本。
2. 给每位审查者匿名pair音频与一句场合说明，隐藏供应商、模型、开发者偏好及另一人的分数。pair顺序随机；同一pair的两模式都要听，才能评连续性。先独立听，必要时重听并记录次数；不能仅凭文字或voice名称评分。
3. 五项分别给1–5分：**可理解**（入门者能听出目标意思）、**场合适配**（礼貌与正式/非正式语域合适）、**本地真实性**（像可接受的新加坡英语，而非刻板模仿）、**自然度**（停顿、重音、语流自然）、**跨模式连续性**（示范与对练仍像同一角色）。1为明显不适用，3为需调整，5为适合作样例。任一项≤2须标出秒点及原因，不准以总体印象覆盖分项。
4. 原分写入[voice-ratings.csv](voice-ratings.csv)并保留；两人分歧按[协议](protocols.md)交第三人，仲裁另增记录，不覆盖原评。五维各自均分须≥4/5；任一样本任一维≤2必须修复并独立复核，最多2次修复。未达标即G2不通过，不下调门槛。

## 审查边界与交付

审查者只判断所听片段，不代表所有新加坡英语使用者。`pair-24`的`kopi`须结合语境和发音审查；“听得懂”与“适合入门用户主动说”分别记录。带时间、价格、学校、医疗、工资或交通内容的句子都是虚构沟通练习，不能被解读为实际机构给出的结论。

交付是60段原音轨、30对配对证据、两名独立原评分及必要仲裁、教学/母语审查记录、修订版本与停止/费用凭证。当前这些真实证据均为0；没有任何本地已验证或正式教学声音可发布。
