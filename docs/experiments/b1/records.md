# 样本矩阵与运行账本

所有CSV的空实际字段表示未测，绝不是0毫秒、成功或免费。matrix.csv是预登记的计划格，status均planned；runs.csv只有一行schema_template，不计实验数。运行时每次真实启动追加attempt行，original_id连接首次与最多一次重试，plan_id回指矩阵。未发出请求的planned/淘汰格只进计划完成率，不冒充实际启动；发出后失败不可删出正常启动分母。

| 矩阵组 | 预设行数 | 固定与变化 |
|---|---:|---|
| X1 | 300 | 5环境×2入口×5语言×6路径；语言依次为zh-Hans、id、ja、ko、hi；同一手机完成、取消重试、重复回调、失效state、网络失败、Google外部接续（微信入口最后一格明确不适用） |
| X2 | 60 | 30对，每对TTS和Realtime；三起点各10对；角色A/B各15对；慢/自然与正式/非正式各15对；四格7/8/8/7 |
| X3 | 120 | 三路线各30新任务+10连续；case_id、脚本/音轨hash跨路线同一；30任务四格8/7/7/8；连续2/3/5分钟4/3/3 |
| X4 | 120 | 100新目的四格各25；20专项=10退出+10断线，预先分组。前30正常格分别标句/动作检验ID；每次A-B-A与同角色练习 |
| X5 | 6 | 华语近零基础3、非华语近零基础3，仅候选名额，无真人名单 |

同输入必须有脚本文本、音轨SHA-256、参考图SHA-256、角色ID、resolution/fps/时长及导演脚本hash；“相同提示”不是同音轨。未填hash不能运行跨路线比较。连续课件按完整课件ID分母，内部10秒块数量与费用另记。X4全新音轨的hash不能借用X3。

记录至少覆盖：预期/实际/结果/失败原因；操作者及审查者匿名ID；设备/网络/地区/冷启动与角色状态；精确模型/SDK/锁文件hash/调用参数；各时间点及同一单调时钟/校时误差；两流session和track ID；每类token/角色秒数/下载与录存量；费用、预留、截止与退出凭证；原素材/固定输出/重播hash；独立评分和同意版本。证据路径只引用受控位置，不写真实身份、密钥、token或带签名下载链接。

所有必需时间点以毫秒记录，missing保留原因；负时差、未同步时钟或缺手机实录不可放行。协议中的p50/p95使用nearest-rank并保留N和排序输入；正常失败的放行延迟∞，不得用成功子集替代。完整ready、首帧、实际首段播放独立字段。前后台/断线专项不重新归组。模型或脚本版本变化形成新matrix_revision，旧数据不覆盖。

voice-ratings.csv有30对×2独立审查者=60个待评分格；五维保留1–5原分、低分秒点、是否需要第三人及最终复核证据。第三人/重生成追加行，不改原判。身份映射仅研究负责人保管；对评分员不显示供应商/模型和其他评分。X5另在runs的step_observations字段引用逐步观察，不把“完成会话”替代“独立到理解活动并求助”。
