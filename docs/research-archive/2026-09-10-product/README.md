# 产品规格研究与验证档案

核查日期：2026-09-10。主交付为项目根目录 `spec.md`，不是第三份痛点报告，也不是已经批准的开发计划。

研究沿用前两份报告的原证据，不重新累加成样本人口。新增技术研究通过官方资料、公开 GitHub 仓库和论坛作者的一手帖子校验。`sources.json` 是本次纳入来源的规范台账；`raw/` 保存可取得的检索结果、网页摘取、README 和元数据，某些工具响应含截断，不能视为完整网页存档。

本次纳入 39 项：20 项官方资料、11 个技术仓库、7 个论坛主题、1 个工作流来源。论坛分布为 V2EX 3、LINUX DO 1、Hacker News 1、OpenAI Developer Community 2。BabelDuck 与 Lingdaily 的帖子和仓库关联引用，不是相互独立的产品数量。

方法：先识别用户体验所需能力，再找公开实现与失败案例，最后回到官方文档检查现行能力、退役日期、接入条件和许可。搜索覆盖掘金等更多线索平台，但未读到可靠原文或仅有转载的内容不纳入独立结论。搜索无法穷尽全网，不声称某平台不存在其他资料，也不以论坛数量代表技术成熟度。

关键事实：Sora 2 和 Videos API 将于 2026-09-24 关闭；Realtime 语音不提供视频输出；图像生成不等于自动绑定动画角色；微信电脑网站授权不等于手机同机登录已经解决。地域范围已获用户确认：第一版服务新加坡等支持地区，保留微信。

建议方案为 OpenAI 内容/图像/语音与可编程卡通组合，仍需 D01 确认。零基础教学、真实本地语音、移动浏览器运行和学习迁移均为后续验证目标，未运行付费 API、未做声学评估或学习实验。

文件说明：

- `sources.json`：39 项来源、原日期、访问程度、用途和限制。
- `raw/official-fetches.json`：初次 DNS 失败及按权限升级后成功读取的记录；失败未被隐藏。
- `raw/repo-*.json`：仓库元数据/README 的实际读取结果，须连同访问说明阅读。
- `REVIEW.md`：独立只读评审、处理记录与剩余闸门。
- `document-qa.json`：文档覆盖、链接和 PDF 验证结果，不是应用测试报告。
- `build_spec_pdf.py`：从唯一规范源 `spec.md` 生成阅读版；不改变原痛点报告。
