## 1. 结论摘要

- **问题一：控件太多，"一屏一个主动作"这条规则被 C4–C9 冲淡了。** 开口对练页（c8-resume.png、c9-goal-line.png）在主按钮"开始说"下面又堆了 4–5 个次按钮：用母语说、我想一想、选意思、需要提示、结束练习。上方还有 4 个听力按钮、两组单选、1 个复选框，以及"重看场景"和"返回…"，同时可见约 15–17 个控件。零基础、怕开口的用户不知道先按哪个。`scene-practice.tsx` 第 330–408 行几乎把所有能力都平铺在页面上。
- **问题二：每页重复"系统层"信息，真正的内容被挤到下面。** 每一页都有品牌字标、口号、语言下拉框、h1、元信息行（"约12秒短片 · 非5–8分钟… · 辅助语言尚未经母语审查"）、保存状态和"重试读取"按钮、页脚和试验版说明，有的页还有"大字号/减少动画"开关（practice.png、sentences.png、c8-resume.png）。在 320px 宽的屏幕上，视频要到约 360px 处才出现，主按钮要滚过一屏半才能看到。
- **问题三：视觉层级太平，全是带边框的白按钮加浅绿卡片。** 次按钮、工具按钮、卡片内按钮的样式几乎一样（1px 绿边、8px 圆角）。卡片里还套卡片（c6-coach.png）。radio 和 fieldset 用的是浏览器默认样式。"我的场景"和"生成记录"（c5-library.png、c9-records.png）在卡片里再套一层灰底引用块，留白多而信息少。整体看起来像表单，不像学习 App。
- **改法：** 采用 Duolingo 类的固定结构。顶部一条细进度条，中间只放一个内容，底部固定操作栏里只有 1 个主按钮，最多再加 1 个次按钮；其余功能放进"更多"或"帮助"底部弹层，按需展开。对练页参考 OpenAI Realtime 和 Pipecat：中间放一个大麦克风按钮，辅助功能排成一行图标。
- **不换技术栈，也不加依赖。** 底部弹层用原生 `<dialog>` 加 CSS，折叠用 `<details>`。HANDOFF 要求不要随手更新依赖，Vaul 也已停止维护。shadcn 和 Radix 只借鉴交互方式和可访问性规范，不安装。
- **保留无障碍名称和 test id。** 收进弹层的按钮，文字和 `data-testid` 一律不改。现有测试有 326 处 `toBeVisible`，所以有些按钮从默认可见变成默认隐藏后，测试一定会变红。必须先按先红后绿的流程开一个 UI 批次。
- **工作量预估：** 令牌、按钮体系和共享外壳约 1 天；对练页和学习四页约 1.5–2 天；入口、库和记录约 1 天；回归测试和截图另计。

## 3. 逐屏简化方案

### 3.0 共享外壳（所有登录后页面）

- **顶部栏：** 高 56px，sticky 固定。左边是返回 ‹（44×44，aria-label 沿用原来"返回…"的文案），中间是短标题（16px、600 字重、单行省略），右边是 ⋯ 更多。品牌字标和口号只在场景输入首页出现。
- **语言下拉框：** 移进"更多 → 界面语言"。首页保留一个小号的"地球图标 + 简体中文"文字按钮。
- **收进"更多 → 关于这节课 / 显示"的内容：** 元信息行、页脚（尊重口音、试验版说明）、大字号和减少动画开关。和费用、安全直接相关的提示仍留在页面上。
- **保存状态：** 平时只显示一条 2px 细进度条，再加一个视觉上隐藏的 `role=status` 文本；失败时才显示一行横幅，带"重试读取"文字按钮。
- **底部操作栏 `.action-bar`：** sticky 固定在底部；内边距 12px 16px 加 safe-area；上边 1px 线；只放一个通栏主按钮（52px 高），最多再加一个 ghost 按钮。内容区底部留 96px 空白。
- **"更多"弹层：** 用原生 `<dialog>` 的 showModal 打开。最高 85vh，顶部 16px 圆角，带拖拽条；里面每行 52px，左边图标、右边文字。Esc 或点遮罩可关闭，关闭后焦点回到 ⋯ 按钮。
- **一屏一主按钮规则：** 每个视图里 `.btn-primary` 不超过 1 个，并把这条写进代码评审清单。

### 3.1 场景输入（c7-seed-browser.png）

- **默认可见：** h1（24px）、一行副标题、大输入框（最小高度 120px、16px 字、12px 圆角）、3 个示例 chip、"浏览更多本地场景"文字按钮。
- **场景库：** 分类和种子场景改成点了才打开的底部弹层，不再在页面里展开成一长列。分类 chip 排成一行，横向滚动。
- **移进"更多"：** 我的场景、生成记录、退出登录、界面语言、显示、关于。
- **主按钮：** 底部栏"下一步"，输入为空时禁用。隐私提示缩成输入框下方一行 13px 小字。

### 3.2 关键词与确认（c7-confirm.png）

- **关键词页：** 6 项都改成"标签在上、输入框在下"的紧凑排法（间距 12px）。前 3 项（地点、你的角色、对方）默认显示，后 3 项放进 `<details>`"再补充一点（可选）"。主按钮"生成场景"放在底部栏，"跳过"和"改场景"做成文字按钮。
- **确认页：** 场景原文放在一张卡片里；关键词改成两列 chip 网格（标签 12px 灰色，值 15px）；"你 → 对方"合成一行。费用说明和课程长度放在主按钮正上方，用 13px 字。底部栏放"确认生成"（主）和"再改改"（ghost）。"我的场景"和"退出登录"移进"更多"。

### 3.3 生成状态（c8-cancelled.png、c8-stop-explain.png）

- 页面居中放一个 64px 的状态图标（遵守减少动画设置）、一行状态文字（role 和 test id 不变），以及三点阶段进度：剧本 → 配音 → 画面。
- 生成中没有主按钮，只有 ghost 按钮"取消生成"；完成后主按钮是"观看场景"；失败时主按钮是"重试"。
- 停止前的两步确认改成底部弹层。"我的场景"移进"更多"。

### 3.4 观看

- 视频放在最上方，12px 圆角；下面是英文字幕条（17px）。首播只显示英文字幕。
- 视频下方只放一行图标工具：上一句、中间 56px 圆形播放按钮（挂 `scene-play`）、下一句、字幕开关、0.75× 慢速。每个图标按钮的 aria-label 都沿用原文案。
- 底部栏：看完前主按钮显示为禁用，看完后变成"代入角色"。

### 3.5 代入角色

- 两张角色卡，内容是头像圆加"你：… / 对方：…"，test id 不变；配一句说明。底部栏只有"开始学习"。

### 3.6 词组

- 顶部用 4 段步骤条（词组 · 句子 · 接话 · 对练）代替现在的一排按钮导航。
- 每个词组是一行：英文 17px、600 字重，母语释义 14px 灰色，右边一个 40px 喇叭图标按钮，代替原来每行一个描边按钮。
- 底部栏"下一步：句子"。"上一步"改成顶部的返回 ‹，"重看场景"移进"更多"。

### 3.7 句子（sentences.png）

- 每句一张卡：英文 18px、600 字重，母语 14px。卡片右上角放"播放"和"循环"两个图标按钮；循环按钮保留 aria-pressed，名称不变。去掉卡片外面那颗孤立的"循环这句"按钮。
- A-B 循环（两个下拉框和两个按钮）整体移进"更多 → 练习工具"弹层。慢速改成全局一个开关。

### 3.8 提示接话

- 改成对话气泡：对方的句子在左边，用浅灰气泡；"你可以说"在右边，用浅主色气泡，默认点一下才显示答案。"帮我理解"做成对方气泡下的一个 chip。回合切换用一个小分页器（"2/5 ‹ ›"）。
- 底部栏"下一步：开口对练"。

### 3.9 开口对练（改动最大；practice.png、c6-coach.png、c8-choose.png、c9-goal-line.png、c8-resume.png）

**默认可见：**
1. 顶部栏，右侧显示"回合 2/5"。
2. 视频最高 40vh。
3. 目标 chip（只在有目标时显示，`practice-goal`）。
4. 对方气泡（`practice-partner`），下面一排小图标：重听对方、慢一点再听、帮我理解。音频播放时，"停一下"替换掉重听按钮。
5. 我的回复和反馈用右侧浅主色气泡；纠正内容是一行 13px 文字，加"这条反馈不对"文字按钮。不再用卡片套卡片，也不再显示原生 `<audio>` 控件条，改成一个 ▶ 小按钮。
6. 选意思、母语帮助、提示的结果都以气泡形式插入对话流。

**底部固定栏：**
- 中间是 72px 圆形麦克风按钮，名称"开始说"。录音时变成停止按钮，名称"说完了"，外圈显示音量环（遵守减少动画设置）。
- 左边是"需要提示"按钮，右边是"更多帮助"。"更多帮助"弹层里放：用母语说、选意思、我想一想、"没开口时主动给提示"开关。

**移进 ⋯：** 这次想多练什么、纠正多少（改成分段控件）、结束练习、重看场景、返回我的场景、显示设置。练习设置只在第一回合开始前用弹层问一次，默认值可以直接跳过，之后不再常驻页面。

**恢复上次进度：** "先听对方这句 / 直接继续"改成进入页面时弹出的底部弹层。

**注意：** 跟求助有关的能力（提示、母语、慢速、重听）最多只能藏一层。

## 4. 视觉规范（基于品牌绿 #225d48）

```css
:root {
  --bg:#fff; --surface:#f4f7f5; --surface-2:#e9f0ec;
  --ink:#173f36; --text:#2c4840; --muted:#5f7068;
  --line:#e1e8e3; --line-strong:#b9cabf;
  --primary:#225d48; --primary-hover:#1a4a39; --on-primary:#fff;
  --primary-soft:#e3efe8; --on-primary-soft:#1a4a39;
  --accent-warm:#be7232; /* 只用于焦点环 */
  --success:#2f7a4f; --success-soft:#e5f3ea;
  --warning:#9a5b12; --warning-soft:#fbf0e1;
  --danger:#a33a2c;  --danger-soft:#fbe9e6;
  --overlay:rgb(15 30 25/.45);
}
```

旧变量名保留成别名，避免大面积改动。

**字号**（都乘以 `--text-scale`，大字号开关继续生效）：

| 级别 | 字号/行高/字重 | 用途 |
|---|---|---|
| display | 28/36/650 | 首页 h1 |
| title | 22/30/650 | 各页 h1（现在 32–36px 偏大） |
| headline | 18/28/600 | 英文句子、对方气泡、弹层标题 |
| body | 16/26 | 正文和输入框（输入框必须不小于 16px，否则 iOS 会自动缩放） |
| label | 15/22/500 | 按钮 |
| caption | 13/20 | 说明文字 |
| micro | 12/16/500 | 徽章 |

**间距：** 4/8/12/16/24/32/48。手机左右边距从 24px 改成 16px；区块间距 24px；卡片内边距 16px。

**圆角：** 输入框和 chip 8px；卡片、按钮、视频 12px；弹层 16px；徽章和圆形按钮 999px。

**阴影：** 只给底部栏和弹层加，`0 -4px 16px rgb(0 0 0/.06)`；卡片不加阴影，只靠底色区分。

**按钮：** 统一成 `.btn`，最小高 48px、宽 44px。

| 类 | 样式 | 用途 |
|---|---|---|
| `.btn-primary` | 实心、通栏、52px 高 | 每屏唯一的主动作 |
| `.btn-tonal` | 浅主色底、无边框 | 常用的次要动作 |
| `.btn-ghost` | 透明底、主色字 | 返回、再改改、取消 |
| `.btn-danger` | 红色实心 | 只用在删除确认里 |
| `.icon-btn` | 44 圆形，必须带 aria-label | 工具条图标 |
| `.mic-btn` | 72 圆形 | 对练主按钮 |

**状态：**
- hover：颜色加深一级。
- active：缩放到 0.98（开启减少动画时取消）。
- focus-visible：3px `--accent-warm` 外环，偏移 3px，沿用现在的做法。
- disabled：`--surface-2` 底加 `--muted` 字，不能只靠降低透明度。
- `aria-pressed`：浅主色底加 1.5px 主色边。
- loading：按钮内放 spinner，按钮名称不变。

**图标：** 沿用 `app/guide-icons.tsx` 的风格（1.75px 描边、24 网格、currentColor），补约 14 个：back、more、play、pause、prev、next、cc、slow、loop、speaker、mic、stop、bulb、globe。主按钮一律"图标 + 文字"。

**表单控件：** 单选组改成分段控件，原生 input 保留但视觉隐藏，名称不变；复选框改成开关样式，仍然是 checkbox。

## 5. 实施顺序与风险

**实施顺序：**
1. **S1 令牌和按钮体系：** 只改 CSS 和 className，不动结构。风险最低，效果最直观。
2. **S2 共享外壳：** 新建 AppBar、ActionBar 和用原生 dialog 做的 MoreSheet；语言、页脚、元信息、显示设置都收进去。
3. **S3 开口对练页**（最乱，也是用户最在意的一页）。
4. **S4 学习四页**（观看、词组、句子、提示接话）。
5. **S5 入口、确认、生成、库、记录。**
6. **S6 回顾页和五种语言的长文案检查：** hi 和 id 的文案常常是中文的 1.5–2 倍长，按钮要允许换行，底部栏要放得下两行。

**风险：**
- **e2e 测试：** 测试里有 326 处 `toBeVisible`，按名称找按钮约 600 处；c6、c8、c9 会直接点击"结束练习""用母语说""选意思""我想一想""少纠正"等按钮。项目规定实现阶段不能改测试，所以要单独开 UI 批次：先提交红测（加 `openMore`、`openHelp` 两个 helper），获批后再实现。名称和 test id 不变，测试改动基本只是多点一下。

- **藏起来就找不到：** 求助相关的能力最多藏一层。第一次进入对练页时，用一行 caption 提示"不会说？点提示"。
