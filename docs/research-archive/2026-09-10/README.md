# 研究资料说明

范围：Learning English in Singapore 的跨人群语言痛点；2026-09-10 公开资料阶段。产品定位尚未决定。

## 阅读入口

- 阅读版：`../../output/pdf/singapore-english-painpoints.pdf`，12页、34份引用来源。
- 证据工作簿：`../../outputs/learning-english-research/singapore-english-evidence.xlsx`，研究说明、痛点证据、Sources、检索记录四个页签。
- 文本版：`REPORT.md`，与阅读版同源，保留来源链接。

## 审计资料

- `evidence.json`：86条来源的正文访问情况、证据用途、时间、人群、观察、短摘录、限制、链接及重复组。
- `sources-index.json`：以上86条的简要索引。
- `search-queries.json`：38组、111条检索式。
- `raw/`：检索及打开来源的返回记录、部分原始PDF与核对页面。文件名中的条目号与证据表一致。
- `report-content.json`、`build_report.py`：报告内容、编码定义和PDF构建脚本。
- `report-qa.json`、`workbook-qa.json`、`validation.json`：引用、页数、计数与显示核对记录。

`raw/E014-access.html` 是直接下载NUS论文时返回的访问页面，不是论文PDF；对应论文内容通过网页工具核对，见 `raw/E014.json`。

## 如何使用

优先读取30条主证据及3条反例；18条补充线索不得与正文证据等权。44条“正文”表示相关正文可核对，不表示所有评论均已读遍。检索文本不能代替原文；营销、重复和排除项均保留，便于追溯。

本轮足以支持若干痛点确实存在，不能估算发生率、市场规模或付费意愿。中国主要社交平台和若干人群仍有覆盖缺口；没有新增访谈或代表性抽样，尚未通过全平台充分覆盖验收。
