# Learning English in Singapore

本地流程演示，覆盖 B1 T01–T06 的手机布局、四语入口、逐题引导、学习起点、场景确认与听／练预览。真实登录、语音、
视频尚未接入；无需 API key，不会申请麦克风权限。存档与验收状态以 `tasks.md` 和真实 Stop 回执为准。

## 本机运行

已测环境：Node 24.15.0、npm 11.12.1。浏览器考题还需要本机 Google Chrome。
在项目根目录执行：

```sh
npm ci --ignore-scripts --cache ./tmp/npm-cache
npm --prefix tests ci --ignore-scripts --cache ./tmp/npm-cache
npm run dev
```

打开 <http://127.0.0.1:3000>。服务只监听本机回环地址；按 Ctrl-C 停止。
点击“查看演示说明”，确认展开／收起及键盘 Enter 操作可用。
选择简体中文、Bahasa Indonesia、日本語或 English 后可看两个待接入的登录按钮；
切换语言、打开权限说明、开启大字或减少动画，刷新可保留选择。偏好仅存在本机，
存储被禁用时会提示并保留本次操作。四语言文案均为试验版，尚无母语审查。

点击独立的“预览逐题引导”可进入 12 道核心问题，另有最多 4 道可选问题。
可不知道、跳过、回退、暂停或提前结束；刷新后保留位置与帮助记录。
“演示播放控制”只模拟程序事件，不播放声音；演示选择不用于认定真实能力。
进度读取失败时保留原始记录，新选择仅在本次有效，页面会明确提示。

引导结果中的“学习起点与帮助”区分听力未知、说英语尚未了解和内容建议。
可选择更简单／更自然、慢速／自然速度、减少提示，或恢复当前建议；这些只改变
练习偏好，不改能力记录，也不播放尚未接入的音频。反馈有误可标记，标记不自动降级。
设置与反馈保存在本机；刷新、换语言和继续附加题保留手选，读取失败时保护旧记录。
档案由已保存的引导记录按固定规则重建；所有演示输入仍排除能力证据。

点击“选择要练的事”可选家校／工作／生活起点，或输入自己想办的事。确认卡可编辑目的、人物、地点和担心点；空缺保持未知。确认后展开“演示准备控制”，依次点“模拟对话就绪”“模拟声音和画面就绪”“模拟检查通过”，然后“预览听与练”。模拟准备不调用生成服务。失败、取消、重试和新旧版本接续均可演示，未保存输入换语言后仍保留。

听／练预览有两位程序绘制的演示角色、四句固定通用英语和两个章节。点击“开始听（演示）”，再展开“演示轮次控制”并点“模拟本句播放结束”，查看角色轮换；可试前一句、整段／章节／单句／A-B循环。随时点“我来练”，由对方先开口，不必听满次数。模拟本句播放结束后再点“模拟经过6秒”才能触发帮助；两级帮助后继续等待回到只听，不催第三次。点“我在想”暂停帮助，明确继续后重新带入。速度按钮只存偏好，当前没有真实变速。

刷新恢复版本、位置与偏好，但活动轮次暂停，须点继续；退出回到场景再进可接续。损坏本地记录保留原值并提示，本次操作临时有效。四语大字及帮助路径经过桌面Chrome模拟窗口检查；不能替代母语审查、真机与真实声音验证。

真实实验准备见 [B1实验包](docs/experiments/b1/README.md)：X1–X5脚本、样本与记录、官方版本/许可/价格、数字预算建议、数据流/D06、同意及后续采样。所有真实结果未测，批准额度与实际产品API费用均0。审查者、主体权限与数据链缺项在 [BLOCKED.md](BLOCKED.md)，后续执行需对应外部条件落实。

## 验证与生产模式预览

```sh
bash .loopwork/hooks/verify.sh
npm run start
```

验证依次执行类型检查、生产构建，以及 222 个浏览器用例和 91 个状态／规则用例，共 313 项。
浏览器用例覆盖 3 个窗口尺寸，状态用例在独立 domain 项目中运行一次。
Playwright 管理自己的 `127.0.0.1:3210` 服务，不复用已有进程；应用截图与
失败记录保存在 `test-results/`。`npm run start` 使用刚才生成的生产构建，
监听 `127.0.0.1:3000`。运行服务不代表发布。

也可按计划中的命令合同分步运行 `npm run verify:offline`（类型检查与构建），
然后运行 `npm run verify:e2e`（浏览器与状态考题，需前一步的构建）。
状态考题通过确定性事件检查首次选择、帮助、重听、故障、恢复和题目上限。
规则考题用明确标注的合成观察数据检查逐档前置、支撑排除、冲突补题和共同题数预算；
它们验证规则计算，不是成人实验、真实音频校准或能力认证。

干净环境复现：在新的项目副本中先执行以上两个 `npm ci`，再执行验证命令。
依赖下载需要 npm registry；安装后页面和考题不需要外部服务、在线字体或密钥。
两个 lockfile 分别固定应用与测试依赖；不要以安装到最新版本替代 `npm ci`。

目前的 320×740、390×844、1280×800 检查使用桌面 Chrome 模拟窗口。
不等同于 iOS Safari、Android Chrome 或微信真机验收。保护层的实际证据见
`docs/setup-status.md`，当前任务以 `tasks.md` 和真实代存档回执为准。

入口采用系统字体、白底、深绿色和原生 SVG 图标；本轮不生成图像或调用产品模型。
